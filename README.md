# Arabic Princess Battle 🎀📚
### Magical Arabic Academy

**Learn Arabic, Cast Your Magic!**

Game edukasi kuis battle Bahasa Arab untuk siswa SMA kelas XI (khususnya putri), dengan tema cute pastel magical academy.

## Fitur yang Sudah Berfungsi

- ✅ Mode Solo vs AI
- ✅ Mode Solo Practice
- ✅ 50+ soal Bahasa Arab kelas XI (Mufradāt, Qawā‘id, Tarjamah, Qirā’ah, Insya’)
- ✅ Teks Arab dengan font Noto Naskh Arabic + dukungan RTL
- ✅ Sistem HP, damage, timer 15 detik
- ✅ Animasi serangan sihir
- ✅ XP, Koin, Level, Badge
- ✅ Keyboard + Touchscreen
- ✅ Responsif laptop / tablet / HP
- ✅ Bahasa antarmuka Indonesia + penjelasan kaidah

## Multiplayer
Framework siap. Perlu setup Firebase (lihat di bawah). Mode solo **tidak** butuh internet.

## Cara Menjalankan

1. Extract ZIP
2. Buka folder `arabic-princess-battle`
3. Double-click `index.html` atau jalankan `npx serve .`
4. Mainkan!

## Tim
- **🌸 Wardatul Lughah** — bunga, kosakata, kristal ilmu
- **⭐ Nujum Al-Arabiyyah** — bintang, nahwu, kaligrafi

## Materi
- **Mufradāt** : kosakata pemuda, kesehatan, pendidikan, teknologi, lingkungan, budaya, profesi
- **Qawā‘id** : jumlah ismiyyah/fi‘liyyah, mubtada’-khabar, fa‘il-maf‘ul, na‘at, idhafah, dhamir, fi‘il, huruf jar
- **Tarjamah** : Arab ↔ Indonesia
- **Qirā’ah** : pemahaman bacaan pendek
- **Insya’** : menyusun kalimat

## Multiplayer Setup
1. Buat project di Firebase Console
2. Aktifkan Realtime Database
3. Isi config di `js/multiplayer.js`
4. Tambah script Firebase di `index.html`
